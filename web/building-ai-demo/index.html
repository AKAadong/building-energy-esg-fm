建筑能源 · FM · ESG 场景演示

对接 Langchain-Chatchat 知识库对话 API（/knowledge_base/local_kb/{知识库}/chat/completions）。 RAG 对话页对齐 WebUI「知识库问答」：多轮历史、匹配条数、分数阈值、prompt_name；其余页为单轮场景模板。

RAG 对话（WebUI 同款）

对话模式：知识库问答。使用上方「知识库名称」与「模型名」；下方仅影响本页多轮会话与检索参数。

智能运营优化

视觉无人态、能耗与 FM 知识结合，生成可落地节电/运行建议（模板 smart_ops，亦可选 building_fm_esg）。

FM 设施管理

设备异常、告警与运维知识库 → 诊断步骤与注意事项（模板 fm_maintenance）。

ESG 评价

ESG 指标、披露与合规知识 → 提升建议与条款解读（模板 esg_compliance）。

系统问答

面向知识库的通用专业问答（模板 system_qa）。

若浏览器直连 Chatchat 报 CORS：请在 Chatchat basic_settings.yaml 中设置 OPEN_CROSS_DOMAIN: true 后重启； 或使用 python3 scripts/serve-building-ai-demo.py 通过本页同源 /api 代理访问。
